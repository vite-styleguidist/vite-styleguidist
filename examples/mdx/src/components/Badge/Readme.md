`Badge` is documented in plain Markdown, in the same style guide as the MDX pages: adding MDX changes nothing for the `.md` files that are already there.

```jsx
<Badge>Neutral</Badge>
```

```jsx padded
<Badge tone="success">Shipped</Badge>
<Badge tone="warning">Delayed</Badge>
```

When a component folder has both a `Readme.md` and a `Readme.mdx`, the Markdown one wins.
