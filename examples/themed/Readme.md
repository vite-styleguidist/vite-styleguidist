# React Styleguidist themed example style guide

> **Note:** This example uses the local build of Styleguidist (`file:../../`). Before installing, run `npm ci && npm run compile` in the repository root.

This example customizes the look of the style guide with the `theme` and `styles` options pointing to files (`styleguide.theme.js` and `styleguide.styles.js`).

How to start locally:

```
git clone https://github.com/styleguidist/react-styleguidist.git
cd react-styleguidist/examples/themed
npm install
npx styleguidist server
```

Then open [http://localhost:6060](http://localhost:6060) in your browser.
